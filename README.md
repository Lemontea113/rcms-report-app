# 정산 업무 자동화 프로그램

과제번호 목록을 엑셀로 올리면 필요한 정보를 자동으로 모아 엑셀로 만들어 주는 Windows 프로그램입니다.
첫 화면에서 기능을 골라 사용합니다.

| 기능 | 하는 일 | 업로드할 엑셀 |
|---|---|---|
| **RCMS 사용실적보고서 조회** | RCMS 사용실적보고서의 기관명·연구책임자·연구기간·공동기관 수집 | "과제번호" 열 |
| **이지바로 연구원정보 수집** | 이지바로 상시점검 관리 화면의 기관·사업자번호·연구책임자 연락처 수집 | 1열 과제번호, 2열 년도 |

## 설치 방법 (사용하는 분)

1. [최신 버전 다운로드 페이지](https://github.com/Lemontea113/rcms-report-app/releases/latest)에서 `RCMS-Report-App-Setup-x.x.x.exe`를 받습니다.
2. 받은 파일을 더블클릭합니다.
   - **"Windows의 PC 보호" 파란 창이 뜨면** → `추가 정보` → `실행`을 누르세요.
     (프로그램에 유료 인증서 서명이 없어서 뜨는 안내이며, 프로그램 자체의 문제는 아닙니다.)
3. 설치가 끝나면 바탕화면과 시작 메뉴에 **"정산 업무 자동화"** 아이콘이 생깁니다.

> **Google Chrome이 설치되어 있어야 합니다.** RCMS·이지바로 로그인 창은 Chrome으로 열립니다.
> Chrome이 없다면 https://www.google.com/chrome 에서 먼저 설치해 주세요.

## 사용 방법

### RCMS 사용실적보고서 조회

1. 첫 화면에서 **RCMS 사용실적보고서 조회 → 시작하기**를 누릅니다.
2. "과제번호" 열이 있는 엑셀 파일을 선택하고 **수행**을 누릅니다.
3. 새로 뜨는 Chrome 창에서 RCMS에 로그인합니다.
4. 프로그램으로 돌아와 **로그인 완료**를 누르면 자동 조회가 시작됩니다.
5. 끝나면 **다운로드**를 눌러 결과 엑셀을 저장합니다.

### 이지바로 연구원정보 수집

1. 첫 화면에서 **이지바로 연구원정보 수집 → 시작하기**를 누릅니다.
2. 엑셀(1열 과제번호, 2열 년도)을 선택하고 **업로드**를 누릅니다.
3. **로그인 창 열기**를 누르고, 새로 뜨는 Chrome 창에서 GAIA에 로그인합니다.
4. 프로그램으로 돌아와 **시작**을 누르면 상시점검 관리 화면으로 이동해 자동 수집합니다.
5. **결과 엑셀 다운로드**를 눌러 저장합니다. 팝업 화면 캡처는 `다운로드` 폴더의
   `날짜_이지바로_책임자정보_캡쳐` 폴더에 저장됩니다.

> 조회가 진행되는 동안 **← 처음으로**를 눌러 다른 화면에 다녀와도 작업은 계속됩니다.

## 업데이트

새 버전이 나오면 프로그램을 켤 때 **"새 버전이 나왔습니다. 지금 업데이트할까요?"** 안내가 뜹니다.
`업데이트`를 누르면 내려받은 뒤 다시 시작하면서 자동으로 설치됩니다.

## 문제가 생겼을 때

프로그램 기록 파일을 확인하거나 전달해 주세요.

```
%APPDATA%\RCMS Report App\logs\main.log
```

(파일 탐색기 주소창에 위 경로를 붙여넣으면 열립니다.)

## 개발자용: 새 버전 배포하는 법

1. `package.json`의 `"version"`을 올립니다. (예: `1.1.0` → `1.1.1`)
2. 변경 사항을 커밋하고 GitHub에 올립니다(`git push`). 릴리스 태그가 GitHub의 최신 코드에 붙기 때문입니다.
3. 배포 명령을 실행합니다. (GitHub CLI `gh`에 로그인되어 있어야 합니다.)

   ```bash
   npm run release
   ```

   웹 화면 빌드 → 설치 파일 생성 → 업데이트 정보(`latest.yml`)와 설치 파일의 짝 검사 →
   GitHub Releases 업로드까지 한 번에 진행됩니다.
4. 사용자들은 다음에 프로그램을 켤 때 업데이트 안내를 받습니다.

### 기타 명령어

| 명령어 | 하는 일 |
|---|---|
| `npm run dev` | 웹 화면만 개발 모드로 실행 (http://localhost:3100) |
| `npm run app` | 프로그램 창으로 실행해 보기 (설치 파일 없이) |
| `npm run dist` | 설치 파일만 만들기 (`dist` 폴더, 업로드 안 함) |

### 구조

- `src/app/page.tsx` — 첫 화면(기능 선택)
- `src/app/rcms`, `src/lib/*.ts` — RCMS 사용실적보고서 조회
- `src/app/ezbaro`, `src/app/api/ezbaro`, `src/lib/ezbaro` — 이지바로 연구원정보 수집 (기존 ezbaro-automation 프로젝트에서 옮겨 옴)
- `src/lib/loginBrowser.ts` — 두 기능이 함께 쓰는 Chrome 로그인 창 열기
- `ocr-data/` — 이지바로 성명·휴대폰을 읽는 글자 인식(OCR)용 한글·영문 데이터
- `electron/main.js` — 프로그램 본체: 화면 서버를 내 컴퓨터 안에서만 켜고, 창을 띄우고, 업데이트를 확인
- `scripts/` — 설치 파일을 만들 때 쓰는 보조 스크립트
